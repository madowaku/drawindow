# v0.11 D研究：実装結果と採用保留

## 現時点の判断

本編はAを維持する。Dは認識を賢くする方式ではなく、同じ解釈を受け取ったときの小さな演技の仮説である。Aと同じ認識結果を使うので、精度・９リンク改善という成果は主張しない。v0.10の20合成ケース（正解クラスあり10件、Bは2改善/6悪化、Cは2改善/4悪化）は再現でき、今回その候補選択ロジックは本編へ入れていない。

「相手の絵を見る」根拠はAに置き、「自分の絵の続きを少し想像する」態度だけをDで試す。予想を外しても絵を受け止める表情になっているかは、実際の試遊で判断する。Aが自然なら何も変えない。

## 未検証と次の実験

1. **人間２人以上のブラインド試遊**。しずくらしさ・親しみ・責められた感じを優先し、気づかれない反応も結果として記録する。現時点で人間参加者ゼロ。
2. 同一記録の再生は表情比較用。静止絵と短縮した時計なので、実プレイの間・楽しさの代用にしない。実プレイX/Yの追加セッションは異なる絵・モデル結果という交絡を明記する。
3. 240/160ms、最大２回という初期設定の自然さ。まずD対A、その後に頻度/長さを一つずつ比較し、９リンク最大化へ最適化しない。
4. Android実機の指/ペン、端末性能、BGM出音、機内モード、ホーム復帰。狭いChromium画面は実機受入ではない。
5. 非表示抑制はhook/replay自動試験で確認した。headless CDPのfreezeはdocument.hiddenにならなかったため、実タブ切替の受け取り方は未確認。復帰直後の表情の自然さも人が見る。
6. 日本語描き間違いとDの間、夜の受け取られ方、unknown/エラー後の安心感。現ローカルモデルがuncertainを返さない場合、THINKINGを出すためにスコア閾値を導入しない。

正式採用は上記の試遊後の別判断とする。数字が同じでも、予想と違う絵に対して「受け止めた」と感じられるかを観察する。説明や反応がうるさくなるならDを弱めるかAを維持する。
