# DRAWINDOW v0.4 — しずく高解像度候補

2026-10-18 JST / Issue #4。**4枚を比較候補として追加、本編の正式素材は継続。**

## 正式設定と制作

`CHARACTER_SHIZUKU_v0.2.md` と、既存の承認neutral原画像・表情アトラスを基準にした。
1024×1536のユーザー提供原画像に対し、現行アトラスは1536×1024を4×2に分割し、
各ポーズが384×512。現行表示では高DPR・大きな窓で顔や髪が拡大される。

原本は改変せず、新しいcanonical neutralをImageGenで編集生成した。
共通マスターから4ポーズの一覧を1回で制作し、その後、マスター＋一覧を参照して
BREATH / DRAWING / SMILEを各1回、高いネイティブ解像度で描き直した。
一覧だけでは543×723程度のセルになり、微笑みも閉眼になったため、一覧は不採用。
SMILEを開眼・小さな閉じた口の笑顔へ修整した。

| 内容 | 原画 | 配信用 | 状態 |
| --- | --- | --- | --- |
| canonical NEUTRAL | 1086×1448 PNG alpha | 768×1024 WebP | 候補 |
| BREATH | 1086×1448 PNG alpha | 768×1024 WebP | 候補 |
| DRAWING | 1086×1448 PNG alpha | 768×1024 WebP | 候補 |
| SMILE | 1086×1448 PNG alpha | 768×1024 WebP | 候補 |
| THINKING / SHY / CURIOUS | 既存 | 384×512 | 正式素材をそのまま利用 |

これは低解像度セルの単純拡大ではない。PNGから縮小だけを行い、WebP quality94、
alphaQuality100で保存。4枚合計約0.90MB。全て透明・半透明の縁を保持し、
青背景でも確認した。曇り、窓、背景、文字は人物へ焼き込まない。
交差する銀ピン、青灰色の瞳、アッシュブラウンの髪、青いリボン、白い襟、
長いアイボリーの袖と指先を維持する方向で制作した。新しい表情の種類は増やさない。

両目の中点を目視測定し、旧素材と同じ50%/39.2%の表示目標へ合わせた。
候補は原画の腰上範囲が広く顔が小さかったため、**4枚共通の1.28倍**を
目の中点中心に適用。ポーズごとの引き伸ばしはしない。
瞬きは旧画像の混入を避け候補側では止める。画像失敗時は旧neutralへ戻る。

## 比較と検証

`/?character-preview` で新旧、全ポーズ、昼夜、ガラス、動きを切り替える。
本編は `artSet=current` が既定。候補4枚以外は現行画像であることを画面にも記す。
6画面条件×7ポーズ、画像読み込み、横はみ出し、動きの停止／再開を検査した。
ポーズ切り替えは既存180msのcrossfadeで、reduced motionでは停止。
目の位置は記録した座標に基づく。完全な骨格追従・Live2D化ではない。

現行の7ポーズ、原本、部屋、BGMのハッシュを従来manifestと照合し保持。
新しい素材と入力原本のSHA-256は `assets/shizuku-v04-manifest.json`、
全5回の正確なプロンプトは `docs/shizuku-v04-imagegen-prompts.json`。
再処理は `node scripts/prepare-shizuku-v04.mjs`。
生成は組み込みImageGen、追加の外部アニメーションサービス・有料契約なし。
ユーザー提供原本を基にしたAI編集で、新しい権利やライセンスは設定していない。

**残る判断**：本人による顔・絵柄・衣装・髪型の承認、Androidでの繊細さ、
通常モーションの自然さ、全7枚を新マスターへ揃える採用範囲。
正式設定には「肩にかからないボブ」とある一方、原本の細い毛束は肩へ伸びる。
今回は原本の識別性を優先して毛束を残した候補なので、採用前にこの点も確認する。
自動alpha/hash検査を、絵としての承認や本物の指先接触の保証にはしない。
