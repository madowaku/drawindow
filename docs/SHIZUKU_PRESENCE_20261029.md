# しずくの存在感 — 初見プレイ評価と「受け取りの間」 (2026-10-29)

main `0f38b04`（#34・#35統合済み）を、初めて触る人の視点で日本語・端末内AI・昼を中心に通しプレイした記録です。評価軸は「しずくという存在が感じられるか」。採用済みの昼夜・日英・端末内認識A・Cテンポ・D表情・パジャマ・曇り・絵日記は変更していません。

自動操作（Playwright・合成ポインター）による観測で、人間の試遊ではありません。楽しさ・自然さの判断は本人試遊で確かめてください。

## 本PRの変更: しずくが絵を受け取る間

- 通常の往復：認識が速く終わっても、`recognizing`（しずくは `thinking`、あなたの線はガラスに残る）を最低 **昼800ms／夜950ms** 保つ。遅い認識はそれ以上待たせない。認識の入力・結果・タイムアウト・次の絵の選択は変えない。
- Dの表情は、この間の直後に既存の条件・長さのまま出る。「見る → 表情 → 息」の順になる。
- 5枚目：認識しない仕様はそのまま。同じ時間だけしずくが見てから（見出し「最後のお返事。」、表示「しずくが見ています」）名前入力へ進む。この間は入力・UNDO/REDOを止める。タイトルへ戻ると中止し、何も送らない。
- 適用は製品版のみ。研究ページ（`study`）は計測済みのテンポを保つ。OSの「動きを減らす」では、この間で見せる動き（D表情など）が省略されるので、間も入れない。
- 時間はCテンポの既存の値に合わせた（B案の息と同じ800/950ms）。根拠は「認識が速くなって消えた間を戻す」ことで、新しい演出は足していない。

実ブラウザ（端末内AI・日本語・昼）で、`recognizing/thinking` が各往復約0.8秒見え、続いてDの `curious`／`smile` が出ること、5枚目で「しずくが見ています」が約0.8秒出てから名前入力に進むことを確認した。
