# DRAWINDOW | しずく Character Sheet v0.2

制作名: **しずく / Shizuku**。曇りガラスの向こうで絵しりとりをする、18歳前後の女の子。
キャッチコピー: **ことばより、絵のほうが少しだけ素直。**

本文のv0.2設定を正式設定とし、添付のv0.1設定シートは絵柄・雰囲気の参考とする。
ジャム版では名前を表示しない。プレイヤーにとっては「窓の向こうの女の子」。
将来のストーリー版で名前を明かす余地を残す。

## コンセプト

内気で、初対面では自分からあまり話さない。でも窓に指で絵を描いている間は
不思議と積極的になる。絵が上手ではないと自覚していても、伝わることが嬉しい。
**普段は静か。絵の中では少しおしゃべり。** 優しいが受け身だけではなく、
しりとりが続くと難しい絵にも真面目に挑戦したくなる。

## 正式外見

- アッシュブラウンの肩にかからないボブ。非対称の前髪、片側だけ外へ跳ねる毛束。
- 片側に交差する銀色のヘアピン2本。後ろに小さなくすみブルーのリボン。
- 青みがかった灰色の瞳、少し下がった眉、眠たそうな目元、小さな口。
- 笑うと柔らかくなる目尻。頬の赤みは控えめで、照れ以外は真っ赤にしない。
- アイボリーのゆったりしたニットカーディガン、白い丸襟ブラウス。
- 首元の細いくすみブルーのリボン、長めの袖、チャコールブルーのスカート。

全素材の識別点は **交差する銀色のヘアピン／少し曲がった襟元のリボン／長い袖からのぞく指先**。
今回のゲーム素材は腰上の切り抜きなので、スカートは描画範囲外。

## 表情とゲーム内での使い方

| ID | 正式な動き | 現在のトリガー |
| --- | --- | --- |
| NEUTRAL | 静かにこちらを見る | タイトル、接続エラー |
| THINKING | 首を傾けて眉を寄せ、指先を口元へ | 描く直前、相手の絵を考える間 |
| SMILE | 目元がほどけ、小さく笑う | 自分の絵を描き終え、こちらを見る |
| SHY | 視線を下げ、袖を握る | 描き終えてから最初の760ms |
| BREATH | 唇をすぼめ、窓へ息を吹く | ガラスの曇り直し |
| CURIOUS | 少し目を開き、顔を近づける | 相手が描いている間 |

補助ポーズ DRAWING は指をガラスへ伸ばす。BLINK は制作アトラスに保存するが、
現状のランタイムでは使用しない。自分の絵の再生開始14%をためらいとして止め、
最後の一筆が少し速くなる。描画・息の時計とCanvasを共有する。

**表情は正解・不正解を伝えるものではない。** スコアや推論結果を表情の選択へ
渡さない。しずく自身も相手の絵の本当の意味は知らない。

## 仕草・筆跡・小さな癖

描き始める前に指を止め、考えるときは口元へ。描いている間は少し前のめり、
描き終わると控えめにこちらを見る。恥ずかしいときは袖を握る。
楽しくなると線の勢いが増す。描く絵は少し下手でも雑ではなく、丸い形、
始筆の迷い、大きめの動物の耳と目、少し傾いた左右対称が特徴。
わざと誤解させず、本人はいつも真面目。

緊張すると窓の端へ小さな渦巻きを描いてしまう。本人も気づかない癖。
渦巻きは装飾レイヤーにあり、推論用画像・プレイヤーの記録・スコアへ含めない。
今回の絵の形は既存のQuick, Draw!とオリジナル素材を保持し、始筆と終筆の再生を調整した。
難しい絵を選ぶ新ルールや正解を知る反応は追加していない。

## DAY / NIGHT

昼は明るい自然光。薄れる曇りに顔を近づけ、息で白くしたガラスへ指を伸ばす。
夜は深い青の外景と室内の琥珀色。髪と瞳も深く見え、仕草は少し静かになる。
**衣装・顔・表情画像は共通**。背景、照明、仕草の時間だけを変える。

## アートと動かし方

同じ輪郭・目・髪飾り・衣装、顔の非対称、手描きの線と塗りの揺らぎを守る。
光沢を過剰にしない。キャラクターに背景・曇り・落書きを焼き込まない。
全ポーズは384×512の共通セル、底中央アンカーで揃える。透明度を保持する。

`sprite-pipeline` と `imagegen` skillを使用。アトラス全体を1回の編集で生成し、
別の1回で人物を含まない昼夜の背景を制作した。細かな前傾はブラウザ標準の
Web Animations API、静かな呼吸はCSS。Reduce Motionでは両方を停止する。
画面外・非表示タブでは動きを止め、アンマウント時にアニメーションとタイマーを解除する。
これはポーズ差分による2D演出であり、Live2Dのリグや指先が線を完全追従する骨格モデルではない。

実装: `src/components/CharacterScene.tsx`、`src/lib/character.ts`。
原本・参照: `assets/source/shizuku-v02/`。ハッシュ: `assets/shizuku-manifest.json`。
プロンプト: `docs/shizuku-imagegen-prompts.txt`。
再抽出: `node scripts/prepare-shizuku.mjs`。
制作プレビュー: `/?character-preview`。6表情と描画ポーズ、昼夜、動きの開始／停止を確認できる。
プレビューの動きは明示操作で試せる。通常ゲームは端末のReduce Motion設定を尊重する。

名前を知らなくても、髪飾りと指先だけで「あの子だ」と分かることを目指す。
