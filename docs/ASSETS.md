# Asset provenance

## v0.4 local review candidates

Approved Shizuku assets and all supplied originals remain unchanged. Four new
review-only portraits (neutral, breath, drawing, smile) are derived with the
built-in ImageGen tool from the supplied neutral and formal character sheet.
Each native source is 1086×1448, downsampled to 768×1024 alpha WebP. The game keeps
the approved sprites. The canonical master, rejected matched atlas study,
sources, exact prompts, processing and hashes are recorded in
`assets/shizuku-v04-manifest.json`, `docs/shizuku-v04-imagegen-prompts.json` and
`docs/SHIZUKU_QUALITY_v0.4.md`. No additional third-party artwork or license
assignment is introduced. The original OWL catalogue sample is unchanged; an
original review-only stroke candidate and its source hash are recorded in
`assets/readability-v04-manifest.json`. Owner approval and blind observations
remain separate from alpha/hash/browser checks.

## v0.3 in-game integration

The seven existing transparent character WebPs are preserved byte-for-byte;
no new character generation or paid animation provider was used. A typed
manifest in `src/data/shizukuPoses.ts` records source path, measured eye anchor,
fallback and the drawing pose's fingertip source anchor (128,256 / 384,512).
Front-facing poses are translated toward one shared eye target; oriented poses
use a short180ms transition. All seven source/processed hashes were rechecked.
The reserved existing blink sprite is used as a rare title-only cosmetic blink.

The small stroke-contact glow and sleeve cue are CSS decoration. Its center is
the exact interpolated playback tip, mapped through the same drawing square;
it disappears in pen lifts, at completion and with reduced motion. It is not a
skeletal finger/hand rig. No stroke coordinates or inference image are changed.

### Archived initial scene assets

One built-in OpenAI ImageGen call produced a six-panel, 3-column × 2-row atlas
on 2026-10-17. Top row: DAY; bottom row: NIGHT. Columns: neutral, thinking,
smiling. It uses the first supplied illustration as reference, preserving one
identity rather than mixing the four supplied girls. The full exact prompt is
in [imagegen-prompt.txt](imagegen-prompt.txt). No CLI/API-key fallback, Tripo,
Leonardo or Superdesign image generation was used.

- Supplied reference bytes: `assets/source/supplied-day-reference.png`.
- Untouched generated bytes: `assets/source/character-atlas.png` (1024×1536).
- Final game images: `public/art/{day,night}-{neutral,thinking,smiling}.webp`.
- Transformation: exact equal-grid extraction, no retouching, WebP quality 91.
- Reproducible processing: `node scripts/prepare-character.mjs <atlas-path>`.
- Source and final hashes: `assets/character-manifest.json`.

The source is user supplied; its independent ownership was not researched.
The shipped illustration is transparently generated. It is not represented as
human-drawn art. The selected crop avoids hands; restrained expression, hair,
outfit and camera continuity were inspected in the atlas and game screenshots.
The intended naturalness is an art direction, not proof that all viewers will
perceive it as non-AI artwork.

Research: [Character Expressions by its author on CLIP STUDIO TIPS](https://tips.clip-studio.com/en-us/articles/11319).
The implementation follows coordinated eye/eyebrow/mouth changes and restrained
acting. It does not copy the author's artwork. The supplied reference remains
the primary visual target.

## Girl's doodles

The catalogue has 26 first-letter choices, A–Z. Twenty-three were selected from
recognized=true examples in bounded prefixes of Google's Quick, Draw! simplified
NDJSON. `src/data/sketch-provenance.json` records original key IDs, exact category
URLs, licence and byte-range selection; `src/data/quick-draw-sketches.json` retains
the selected normalized paths. Replay timestamps are synthesized. Queen,
xylophone and yarn are original project strokes, clearly marked as such.

The [official dataset](https://github.com/googlecreativelab/quickdraw-dataset)
is made available by Google, Inc. under CC BY 4.0. Attribution, modification
notice and licence link ship in `public/CREDITS.txt` and `public/licenses/`.
The original recognized flag does not establish this game's API recognition.

## Other assets

DM Sans and Cormorant Garamond are self-hosted through Fontsource, Latin subsets,
with complete OFL texts. Phosphor Icons use the bundled MIT licence. Quiet
breath/glass effects are synthesized locally; audio is muted by default. Frost is the requested
interactive Canvas2D compositing layer, not a raster character substitute.

## Shizuku Doodle Library v0.1

37 additional original vector drawings are authored in `src/data/originalDoodles.ts`.
They are not dataset tracings. Uneven contours and short, readable strokes are
timed with the existing production playback utility. The original 23 Quick Draw
samples and 3 original rare-letter templates retain their geometry and provenance
in `legacySketches.ts`; the existing v0.4 owl review moves to `owlReview.ts` with
identical strokes. No new third-party asset or license is introduced.
`assets/doodle-library-v01-manifest.json` lists all 64 candidates, source references,
maker judgements and source/stroke SHA-256 values. SAFE is a provisional maker
judgement, not a human recognition result. Historic v0.4 manifests are preserved;
their source-file hashes refer to the pre-library file layout.
