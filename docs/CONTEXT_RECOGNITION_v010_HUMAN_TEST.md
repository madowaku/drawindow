# v0.10 人間比較試験の手順（未実施）

## 今回使えるデータ／使えないデータ

v0.9の人間ベンチマークは明示的JSON/CSVにメタデータとTop-3を出すが、画像・ストロークを出力しない。今回確認したリポジトリには、独立した人間の元描画＋前絵文脈＋意図が揃った再推論用セットは確認できなかった。既存のブラウザー自動テスト画像、しずくの線画、スクリーンショットから元ストロークを推測・補完しない。過去の30/32も独立手描きの根拠として使わない。

今回の記録は全345モデル候補を保持するため、モデルの再実行なしで将来の**補正だけ**を再評価できる。モデルや前処理を変更して再推論するには、別途同意を得た実際の描画データが必要。今回の出力にはその元データは含めない。

## 第一段階: 同じ絵とモデル出力による比較

1. `npm run prepare:local-ml` でモデルを準備し、`npm run dev` の `/?context-recognition` を開く。端末内CPU/WASMのため推論サーバーやAPIキーは不要。初回のモデル準備とローカル資源読み込みは必要。読み込み後の通信遮断は別途検証する。
2. パイロットは２人以上、各12枚程度の新しい描画を基準にする。日英を混ぜるなら言語別に件数を残し、同じ人・同じ絵の設定違いを人数や独立標本として数えない。P01/P02の匿名コードを使い、氏名・メール・識別情報を書かない。
3. 実施者が既存の採用絵を選び、正式名を設定して「描き手に正式名を隠す」を有効にする。描き手には絵だけを別の盲検表示／印刷で見せる。入力欄を隠す操作自体は認識に影響しない。正式名を教えてしまった試行は自然な読み違い試験に混ぜない。
4. 描き手は前絵を何と読んだか、次に何を描くつもりかを結果を見る前に私的に記録する。紙等で先に記録し、モデルへは渡さない。UIの評価欄は推論後に表示されるため、後から結果に合わせて意図を作り替えない。語頭を間違えた絵・対応外・落書きも除外しない。
5. マウス・指・ペンで描き「一度だけ認識する」を押す。１回の候補345件からA/B/Cを作る。結果の後で、先に記録した意図と前絵の読みを入力する。意味が本当に対応するモデル分類を評価者が選ぶ。不明なら未評価、対応外なら対応外を選ぶ。近い意味や同音だけを正解にしない。
6. 初回を残したままCのgap/bonus、強さ0/.02/.04/.08、順位範囲などを事前に決めた範囲で比較する。同じ絵は同じ候補を再利用し、「この設定・評価を記録する」で各設定を明示的に残す。良い設定だけを選んで残さず、画像正解を壊した設定も記録する。
7. 匿名コード＋描画fingerprint＋固定文脈を基本の分析単位にする。同じ形の絵を文脈だけ変えて再実行した場合、推論requestIdは別でも独立した人間の絵として件数を増やさない。設定・表情・言語・文脈を分けて集計する。
8. 終了前に本人がJSON/CSVを書き出す。画像・座標・実名は出力しない。ファイルを送信・共有する操作は自動では行わない。メモリー内記録なのでページを閉じると消える。

## 評価は分ける

- 意味: 正しいモデル分類が確定した試行の一致数／評価済み数。花／鼻、くも等の読み一致は別指標。分類が対応外のときは名詞クラス正解率に混ぜず、unknownにできたか・既知語を断定したかを別に数える。
- 補正の影響: Aが誤りでB/Cが正解になった件数と、Aが正解でB/Cが誤りになった件数を**別々に**示す。前絵読み違い、ルール間違い、未対応、明確な画像根拠、曖昧な画像根拠の群を分ける。各人の結果も残す。
- 連鎖: 正式名からの文字上の接続、次の採用見本の存在、実際に遊んで続いたかを別にする。本編はAなので、B/Cの実プレイを観察していない欄は未観察のままにする。
- 体験: 比較画面の感想と、５往復のゲームで感じる楽しさ・テンポ・再遊意向・しずくらしさは別の証拠。全３方式を同時に見た感想を、１方式を自然に体験した証拠と扱わない。

## 第二段階: ゲーム体験と表情の比較（次の提案）

まずA/B/Cを匿名化し順番を入れ替えた結果提示試験で、前絵読み違いのときに自然さが損なわれないかを確認する。Aが最も自然ならAを維持する。

その後、別承認の研究用５往復プロトタイプで方式を固定した試行ブロックを比較する。本編のC採用はしない。各ブロックの意図／実継続／迷った箇所／すれ違いが楽しかったか／もう一度遊びたいかを記録し、順序効果を均等化する。反応が長くなりすぎないかも観察する。

表情は**認識Aを固定した別実験**で比較する。現在の静止プレビューは絵柄比較に過ぎず、実プレイの自然さを証明しない。文脈だけを表情に使うD案（解釈はA）も候補とする。表情と認識を同時に変えて効果を混同しない。

少数パイロットから販売品質や人口全体の精度を宣言しない。今回の描画で設定を調整したら、それは開発用データとなるので、採否には新しい未使用の人間描画を用意する。QuickDraw由来の公開絵は学習データとの重複を除外できない。
