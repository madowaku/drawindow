# DRAWINDOW v0.13 — しずくは何を見た？

## 目的と現在の結論

認識率を創作せず、認識不能の原因を減らし、わからなくても絵を残して続けられる研究版を用意した。日本語対応の欠落は32クラス分を実際に解消した（177→209/345）。モデル、0.05の採用基準、画像だけのA認識、通常の前処理は維持する。救済Bの正式採用と前処理の変更は、人間の試遊後に判断する。

開始点は `main@3dad268c3864aa37fcb1cd6cd72bb9edc84cbe49`（PR #32、CテンポとD反応の統合）。開始時main CIは成功。関連Draftは #29（品質・復元）、#30（文脈認識）、#31（予感研究）。本編へB/C認識を導入しない。

元の `codex/offline-first-v09` の package.json、配布receipt、未追跡Windows包装スクリプト、および既存の9つの別worktreeを変更していない。実作業は `.worktrees/v013-recognition-continuity` / `codex/v013-recognition-continuity` に隔離。アプリ管理worktreeは書込権限外だったため、許可されたリポジトリ配下に専用worktreeを作った。

## 原因分析

| 分類 | 判定する場所・条件 | 保存・測定 | 再試行 |
|---|---|---|---|
| invalid_input | 前処理: 空、2点未満、範囲外、非数、短すぎる線、過大入力 | errorCodeは既存invalid_input、failureReasonを追加 | 線を編集する |
| low_score | 有効な出力のTop1が0.05未満 | 既存invalid_responseと新しいfailureReason | 同じ入力では抑止 |
| unmapped | Top1に日本語名がなく、有効な認識語が作れない | 既存invalid_responseと新しいfailureReason | 同じ入力では抑止。Top2へ降格しない |
| model_unavailable | モデル/WASMロード、コンパイル、実行、runnerの一時的失敗 | 既存unavailable/network/timeoutに対応 | 明示的に最大2回追加。未知の原因も断定しない |
| invalid_output | 出力欠落、345次元不一致、非数、不正なスコア | 既存invalid_responseと新しいfailureReason | 確定的な絵の問題とは断定しない |
| uncovered_letter | 認識語は有効だがreducerが次の絵を選べない | 認識語を保持し、failureReasonを追加 | 同じ語の再推論を促さない |
| wrong_guess | 人間が「違うが納得」「意味不明」を選んだ場合だけ | 自由描画の人間評価から集計。AI結果に上書きしない | 自動修正しない |

以前は low_score / unmapped / invalid_output が同じ invalid_response だった。ローカル失敗後も同じ絵へ最大2回の再試行を提示していた。既存のerrorCodeを残し、optionalなfailureReasonで区別する。旧schema-1保存は読める。旧保存に理由がなければ低スコア等と決めつけない。今後モデル・日本語デコーダー・前処理を更新するときは、保存済みlastLocalFailureキャッシュの無効化を追加すること（今回のモデル・既定前処理は不変）。

「線を足す・描き直す」へ戻ってDONEを押しても、同じ筆跡なら直前の確定的ローカル結果を保持し、再推論しない。編集すれば認識可能。UNDO/REDOで同じ筆跡に戻った場合も同様。失敗した絵は明示操作まで残る。model_unavailableでは穏やかな案内と「もう一度」を維持する。黙ってDEMOへ切り替えない。

## 日本語監査・実装した改善

- [168件の監査表](QUICKDRAW_JAPANESE_AUDIT_v013.md)、[機械可読の判断](quickdraw-unmapped-v013.json)。A 143 / B 17 / C 6 / D 2。Aは候補であり一括採用ではない。
- 採用は32件だけ。眼鏡、砂時計、携帯電話、電卓、マイク等、物の意味が明確な名詞。`bandage→ばんそうこう` は包帯等との曖昧さがあるので採用しない。
- monkey→さる、bird→とりを維持。flower/nose等の同音異義を同じ意味にしない。意味辞書は拡張していない。新語が意味辞書にない場合は同義判定を作らずunknownにする。
- `node scripts/audit-recognition-v013.mjs` は168件の語頭・語尾・正規化・「ん」再開を実reducerでDAY/NIGHT監査。`npm run audit:vocabulary` は全対応語・実セレクタ・実reducerの網羅、各言語/各昼夜256シードの5往復を検査。合成結果は人間の認識率ではない。
- 新規対応を除く認識語、閾値、Top1の扱いは維持する。未対応は136件残る。

## 自由描画と同一筆跡の比較

`npm ci` → `npm run dev -- --host 127.0.0.1` → `/?recognition-benchmark` → **自由描画・前処理比較**。固定12問も維持。

描くつもりの言葉、言語、改善用/最終評価用、入力の出所を先に固定する。モデルへ渡すのは requestId / language / strokes だけで、意図、前の単語、正解、しりとり文脈は渡さない。マウス/指/ペン/キーボードは描画イベントから記録する。

同じ筆跡を1回コピーし、現行、余白1px、余白4px、細線、太線、位置・絶対スケール保持の6条件を**逐次**推論する。モデルは共用し、6モデル同時ロードや並列推論を行わない。通常設定は28×28、4倍スーパーサンプリング、余白2.5px、半径3、アスペクト比保持、中央揃え、学習時の黒背景/明線のまま。

各条件でTop1、Top3、生スコア、日本語対応、失敗理由、準備時間、推論を含む処理時間、次の絵の有無、人間の納得度、Top3一致を記録する。テンプレートが存在することは実際の完走成功と区別する。自動再試行しない。

JSON/CSVは手動ダウンロードのみ。データはメモリ内。画像・筆跡は既定で出力しない。**比較前に明示チェックした場合だけ**再現用筆跡を保持してJSONに含める。チェック解除は保持済み筆跡を破棄する。CSVには筆跡を入れず、数式開始文字をエスケープする。氏名、メール、鍵、秘密情報は入力しない。自由入力の匿名性は本人の入力内容にも依存する。

合成/出所未確認は人間集計から除外し、人間の改善用とholdoutも分ける。1枚×6条件を6枚の独立した絵には数えない。未評価は成功扱いしない。誤認識か納得できる別解かは人間が決める。

## 続け方 A / B / C

| 方式 | 実装・選択 | 利点 | 判断を残す点 |
|---|---|---|---|
| A 線を直す | 通常操作を維持。研究ページでAを選択可能 | 言葉を使わない、意図した絵を残して直せる | 描き直し負担、同じ不能の繰返し |
| B わからないまま次へ | `/?recognition-recovery` のB（既定）。失敗時に本人がボタンを押す | 絵を消さず、5往復を止めない | 新しい絵が自然か、しずくらしさ、結果の理解 |
| C 名前を伝える | 設計比較のみ、正式採用保留 | 意図から続行できる | 言葉を使わない世界観、AIが分かったという誤解、入力負担 |

Bは**画像認識のA方式と併用する続行操作**で、文脈認識Bではない。失敗したプレイヤー絵・認識結果・failureReasonを残し、明示した救済操作をnonComparableReason=recognition_recoveryで別記する。新しいしずく絵の選択に意図・Top2・スコアを渡さない。10枚に失敗絵を含め、そこから次へのリンクは名前が後で分かってもunknown。満点にしない。救済前の入方向リンクは本人の事後意図に従って通常判定する。

5枚目のプレイヤー絵は従来どおり認識せず、そのまま名前つけ・絵日記へ。日本語の「ん」は元の正直な切断・再開であり救済に置換しない。しずくの描き間違い補正、既存の絵、Cテンポ、Dの小さな反応は維持。研究ページでも通常のTempoCanvasとDを使う。

研究A/Bの途中保存は通常ゲームと別のローカル保存先、A/B間も別。再開後の失敗理由・救済マーク・描き直し回数を保持する。続行JSONには絵や筆跡を含めない。完走・救済回数・描き直し回数・自然さ/負担/楽しさ/しずくらしさ/すれ違い/再遊意向を別記する。

Cを将来実装する場合も `playerDeclaredWord` を `recognition.guess` と別に保存し、名前入力した操作と出方向リンクを「本人申告で続行」と表示する。AI成功には数えず、unknown/研究非比較のまま。事前に世界観の受容を聞き、今回は入力UIを本編へ追加しない。

## 検証と限界

実行手順は [人間テスト手順](RECOGNITION_v013_HUMAN_TEST.md)。機械検証の結果は [検証記録](RECOGNITION_v013_VERIFICATION.md)。ブラウザーの合成筆跡、実モデル実行、人間の認識精度・楽しさは別の証拠として扱う。

推薦: 32語の明確な日本語対応と原因分類・再試行案内をレビュー対象とする。前処理は現行維持。続行Bを有力候補として実装済みだが本編採用は試遊後。C、新モデルへの全面交換、文脈認識は採用しない。モデルサイズ8,851,924 bytes、ランタイムとモデル版は不変。新しいモデルは比較していない。

人間の新規20〜30枚、2人以上×12枚、実Androidの速度・メモリー・指入力・BGMの聴感・楽しさ・再遊意向は未測定。500 kB超の既存JS bundle警告も残る。mainへのマージ、公開、販売ZIP更新は行わない。
