# v0.11 匿名A/Dパイロット手順

## 目的と参加

独立した２人以上を初期パイロットの対象にする。人の手描きを正しく認識したかを測るv0.10試験とは別に、しずくの自然さ・親しみ・責められた感じ・しずくらしさを調べる。現時点では参加者ゼロ、感想も未入力。自動テストの合成線やブラウザー操作を人の結果として集計しない。

実施者だけが設計と割り当てを知る。「賢いしずく」「文脈を考える改良版」と事前説明しない。参加者には「二つの表示の感じ方を比べます。正しい答えや、良い方を選ぶ義務はありません」と伝える。撮影・共有は不要。個人名の代わりにP01等を使う。

## 実施

1. 開発サーバーの `/?shizuku-premonition` を開く。研究保存領域は本編と独立。前の参加者の途中データを再利用しない。新しい試験には新規ブラウザープロファイルを使うと確実。
2. 匿名X/Yの割り当ては開始時にランダム化される。提示順はタイトルで入れ替えられる。参加者１と２で先に見せる表示を反転し、DAY/NIGHTも偏らないよう記録する。終了後の検査欄で割り当てを確認するまで開示しない。
3. 最初の表示で通常どおり５往復を遊ぶ。描画前・描画中に認識候補や予想文字を見せない。５枚目には推論しない。途中で表示を切り替えた場合は混合条件として扱う。実プレイのテンポはこの段階で尋ねる。
4. 答え合わせ後、「次の認識直後」で同じ絵・同じ結果・同じ進行をX/Yで順に見る。再推論しない。並べて比較するのは最後にする。再生位置を変えても表示切替で位置は戻らない。
5. 共通時計の再生では通常と同じCanvasで息かけ・ためらい・指先・線を順に再現する。待ち時間の上限圧縮はしない。停止/シークでは途中の線と指先も止まる。非表示/画面外で止まっていた時刻は旧記録にないため、余った実時間は完成後の保持になる。完全なテンポ測定の代用にはしない。動きを減らす設定では通常と同じく完成絵を表示し、指先・追加表情・自動再生を止めるため、Dの短い反応の評価対象にはしない。
6. 未観察の項目は空欄にする。各表示の９項目は1=全くそう感じない、5=とてもそう感じる。責められた感じ・邪魔さは高いほど懸念が大きい。他の項目と単純に合算しない。
7. 自由記述には「どちらが自然だったか」「どちらに親しみを感じたか」「反応の意味をどう受け取ったか」を本人の言葉で記す。誘導して正解を教えない。気づかなかったという回答も有効。
8. 本人の操作で評価JSON/CSVを端末に保存する。描画・名前・認識語を含む再生JSONは、内容を説明した別チェックと保存操作をした場合だけ出力する。自動共有はない。

実プレイをもう一方の表示でも行う場合は、新しい５往復として別に保存する。描き直しやモデル出力が異なるため、表情だけの因果比較とは呼ばない。同一記録の再生と自由プレイの双方から判断する。

## 記録の読み方

予定した提示順と、実際の表示切替・並行表示のログを分けて保存する。`liveLabels` は操作上の実プレイ条件、`renderedExposureLog` は表示・切替の機会の記録で、参加者が注視した証明ではない。再生中のY切替をYの実プレイとして数えない。復元後の記録はpartialと表示され、それ以前の演出は補完しない。ブラウザー終了で評価と過去の演出ログは失われるので、その前に本人が出力する。

## 採否の判断

２人の回答は探索的な事例として扱い、統計的な優劣や全ユーザーへの効果は主張しない。まず責められた感じ・採点された感じがないかを優先する。しずくらしさが薄れたりテンポが悪化したりした場合はAを維持する。良い兆候があっても、DAY/NIGHT・日本語の描き間違い・Android実機を追加確認してから別途採用判断する。
