- [ ] 各条件で端末内AIを選び、自分の絵で5往復。誤認識、分からない絵、次の絵を考える楽しさを分けて記録する。5枚目に認識を要求しないことも確認する。
- [ ] 指と対応ペンで短線・円・三日月・複数線を描く。追従、端の入力、指で目元が隠れる感覚、スクロールとの競合、描いている途中の操作感を確認する。
- [ ] 夜のタイトル／命名は薄い霧とパジャマ、本編は濃い霧で気配が残ることを確認。顔を横切る線の中心から肌・髪・目が見えるか、暗い／明るい輝度で水滴の縁が邪魔にならないかを記録する。
- [ ] 昼の服と夜のパジャマが混ざらず、各表情で目・肩・袖が不自然に跳ねないことを確認する。新しい演出や色調をその場で採用しない。
- [ ] Cの息・線・間・絵日記・またねが「待てる／退屈／落ち着く」のどれに近いかを本人の言葉で記録。Dの短い表情を気づいたか、自然と感じたかを別欄に残す。一般的な優位性は2人以上の追加パイロットでも確認する。
- [ ] 即時スキップ、OSの動き軽減、実際のアプリ切替・画面ロック後の再開を確認。動き軽減を勝手に解除しない。非表示中の演出や音が戻った瞬間に追いつき再生しないか確認する。
- [ ] CLEAR／UNDO／REDOで絵と霧が対応し、途中終了後も操作履歴・命名途中の空白や日本語IME入力を保つことを確認する。
- [ ] 「通信なしで遊ぶ準備ができました」の後に機内モードへ切り替え、ブラウザーを終了・再起動。同じURLで続きから5往復と保存まで確認する。正常終了とOSによる破棄は別記録にする。
- [ ] 保存したPNGをファイル管理／写真アプリで開く。1200×3000の10枚、文字なしの既定、文字ありの選択、長押し保存、ダウンロード名を確認する。
- [ ] 実スピーカー／イヤホンでBGM・効果音・切替・復帰を確認し、音量と心地よさを記録する。自動decode成功を聴感評価に置き換えない。
- [ ] 検証用の読み込み失敗条件で、背景／人物の復帰・通常ポーズへの代替・認識再試行時の絵の保持を確認する。障害の注入方法と回復操作を記録する。
- [ ] itch.io埋め込みでの保存・音声・Service Worker可否は別途、許可された非公開プレビューで確認する。localhost成功からiframeでのオフライン対応を推定しない。
