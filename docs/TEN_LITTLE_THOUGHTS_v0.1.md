# TEN LITTLE THOUGHTS — ending storyboard

Scope: issue #11, existing review_intents → results presentation. Core scoring, recognition and five exchanges stay authoritative. Baseline combines latest Japanese v0.5 and quality gates; existing character work is isolated.

1. Diary: five pairs in chronological Shizuku → player order, original stroke geometry. One pair appears at a time. No words, guesses, links or score before explicit reveal. Immediate reveal/skip always available; reduced motion shows all pairs immediately.
2. Reveal: user explicitly opens interpretations. Nine actual score links appear sequentially, with non-color labels, kana/letter boundaries, terminal-ん restart and coverage exception disclosures. Skip produces identical data. Score is a word-chain measure, never proof of shared understanding. DEMO/incomplete results carry disclosures. Final drawing has no recognition.
3. Goodbye: after all links, user may refog a decorative window containing the ten pictures, with a small score-independent smile. Full results remain available beneath it; return to diary, restart and title are user-controlled. Reduced motion is instant. No autoplay navigation.

Closing copy: known mismatch → “We didn't see the same things. But we kept drawing.”; no observed mismatch and known data → “Each picture held its own meaning. And we kept drawing.”; missing interpretation/intention → “Some meanings stayed unspoken. But we kept drawing.” Japanese equivalents accompany each. A perfect word chain does not establish agreement on meanings.

Souvenir: deliberate local Canvas2D PNG generation, ten original drawings, all nine labeled link states, day/night, language, honest session disclosure, final no-recognition note, Quick Draw CC BY 4.0 attribution/source and drawing-layout adaptation notice. Words optional (off by default); both exports retain link statuses and attribution. No API metadata, upload, Web Share or automatic sharing. Preview/download fallback for mobile, visible failure/retry feedback, object URLs released on replacement/unmount.

Verification: interaction tests for secrecy, explicit reveal, timers/skip parity, unknown/mismatch/perfect copy, restarts, save failure and metadata boundaries. Responsive browser comparisons EN/JA × DAY/NIGHT at 360×800, 720×1280 and desktop; reduced motion, export dimensions/content, download and no outgoing save requests. Full tests, auth checks, production build and itch package. Physical A401OP saving/touch and emotional pacing remain human gates.
