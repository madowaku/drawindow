# C固定の表情比較（v0.12追試）

テンポ試遊で「Cがちょうどいい」という本人の感想を受け、次の比較はC初期値に固定する。これは本人1名の感想で、一般的な優劣やD採用の根拠にはしない。本編・D正式採用は保留。

## 試す

DEVの `http://127.0.0.1:4241/?window-time-premonition` を開く。従来の窓辺の時間画面にもリンクがある。

1. 提示順と日英・DAY/NIGHTを選び、表示XまたはYで5往復する。認識は画像のみのA、最終絵の追加推論はない。
2. 終了後「同じ窓の記録を見返す」で再生。表示を切り替えるか「並べて比較する」で同じ時計の顔を比較する。
3. 「次の認識直後」とシークで表情を検査できる。停止中の顔は選んだ時刻の静止観測であり、実プレイの持続時間とは区別する。自然さの評価は通常再生で行う。
4. 気づいたか、親しみ、責められた感じ、邪魔、しずくらしさを各表示に記録し、本人操作でJSON/CSVを保存する。未試遊の回答は空欄。割り当ては終了後の実施者欄で確認する。

## 固定条件

両表示でCの座標・筆順・ためらい・息・描画時間・描き間違い・ending設定を共有する。Dの純粋な既存判定と表情のみ追加し、昼240ms/夜160ms、認識応答1・3回目の上限も変更しない。次の絵・スコア・9リンクに文脈は渡さない。OS動き軽減が優先。復元は追加表情を再発火させない。

保存DBは `drawindow-window-time-premonition-v012` で、本編・v0.11 D・テンポ比較のDBと分離。X/Y割り当ても復元し、復元以前の試遊記録を補完しない。評価JSON/CSVと任意の描画入りJSONにC条件を明記する。自動送信なし。
