# DRAWINDOW v0.11 D案「しずくの小さな予感」設計

## 判断と境界

PR #30のスクロール修正済みHEAD 63e7c8b0e12122d6eae3133931d057f093c99457を起点にする。AとDの違いは研究用の顔の指定だけ。認識は同じcreateQuickDrawRecognizer、同じgameReducer、同じ５往復・９リンク・採用カタログ・命名・エンディング・音楽・PNGを使う。本編はAのまま、研究のコードはsrc/devに限定し既存の製品ビルド隔離を維持する。

本編画面を複製して別のルールを育てる案より、DEV限定の表示・観測・保存バックエンドの差し込み口を設けて実際のAppを再利用する。研究は独立したIndexedDBに保存し、同じオリジンの製品途中保存を上書きしない。表示切替はゲームイベントを送らず、追加推論や追加待機を発生させない。

## 感情の候補

純粋関数の入力は、直前のしずくの正式名、言語、実際のA認識結果、ラウンド・昼夜。プレイヤーの意図・前絵の読み・スコアは渡さない。語頭・語尾と濁半濁音、小書き、長音は既存words.tsを使う。

- 一致: smileを短く。祝福の文字・点数・効果音を足さない。
- 不一致: curiousを短く。叱責や失敗マークにしない。
- 不確か: 明示的uncertain=trueがある場合だけthinking。未較正スコアやalternativesの数から自信を推定しない。現ローカルモデルが不確かフラグを返さなければ、曖昧さを演出するためにフラグを捏造しない。
- unknown／error／mock／不正な文脈／「ん」での再開: 追加の顔を出さず既存表示と再試行・描き直しを優先。

## 頻度と時間

認識が成功して次のgirl_breathへ移ったことを確認してから、既存の待機・息かけ時間に重ねる。新phaseを作らず、reducerを待たせない。候補は４認識分記録できるが、実表示は１・３回目の応答だけ（最大２回）を初期研究設定とする。昼は短く、夜はさらに短い静かな表情だけにする。具体時間は開発仮説で、人間の自然さを検証した値とは呼ばない。

既存の日本語描き間違いが選ばれた遷移はDを抑制し、notice/flustered/redrawを優先。少女の息かけ・描画phaseを出ると即時終了する。５枚目に追加推論しない。reduced motionでは追加の短い顔切替を抑制し、既存の静かな演技を保つ。

## 非同期・復元

採用済み認識遷移のsessionId/requestIdを一度だけ処理する。古い応答、再試行失敗、re-render、A/Dの切替では再発火しない。最初に観測した状態やRESTORE_SESSIONでは過去の認識を遡って演じない。タブが非表示になったら追加表情とtimerを終了し、戻っても古い表情を再生しない。本編のCanvasと既存キャラクターは従来どおり非表示時の時計を扱う。

## 比較と記録

研究モード /?shizuku-premonition は実際のAppを端末内AIで遊ぶ。観測イベントはrecognizerの外で記録し、同じ初期状態・game events・A結果をreducerで再生してA/D同一性を検証する。記録済みの同じstate/絵と同じ時計を使う並行／順次の比較再生を用意し、再推論しない。

匿名提示X/YでA/Dを割り当て、提示順を変更できる。描画中は割当・仮説・認識語・語頭・理由を隠し、検査欄は終了後にだけ開く。採点や賢さを説明しない。評価は自然さ・親しみ・気づき・責められた感じ・邪魔さ・テンポ・昼夜・しずくらしさ・再遊意向と自由記述を別に保存し、少人数を一般化しない。

PR #31追加修正では、完成サムネイルを廃止しWindowCanvasへDEV限定の読み取り専用時計を渡す。strokesAtProgress/getPlaybackTip/getPlaybackDurationと14%のためらい、息かけ・濡れた線・既存指先をそのまま共有する。X/Yは単一progressで動き、独立した完了コールバックや再推論を起動しない。比較表示は記録の全イベントと時間差を保持し、通常の息かけ・描画時間を下回る古い/合成トレースも短縮しない。旧記録には非表示/画面外の停止区間がないため、その余剰実時間は保持として残し、完全な実時間再現とは呼ばない。入力側の同一ジェスチャーの記録統合は従来どおりで、しずくの描画順は元のストローク時刻から再構築する。Dの240/160ms設定は変更しない。

記録は本人の明示操作でのみローカル出力する。既定は評価と演出メタデータだけ。描画を含む再生JSONは内容を明示した別操作にし、外部送信しない。途中復元は研究ゲームを再開するが、それ以前の演出時系列を新たに作らない。不完全記録は不完全と表示し、揃った５往復として比較しない。

評価の予定提示順と実際の切替・並行表示の機会は別フィールドに記録する。表示機会は注視や気づきの証明にはしない。再生で切り替えた表示は実プレイ条件に足さない。評価はメモリー上に保持し、ゲーム途中保存には混ぜない。保存復元後には過去の感想・演出イベントを捏造しない。

## 作業と検証

1. 純粋な表情選択と一度だけの表示制御を分離し、日英・エラー・再試行・復元・非表示・reduced motionのテスト。
2. 記録/reducer再生とブラインド評価を独立実装し、A/Dの認識・次絵・９リンク・スコアが一致するテスト。
3. AppにDEV限定のlocalOnly／表情／event観測／保存バックエンド差し込みを追加。本編の既定動作を維持し、製品にsrc/devが含まれればbuild失敗。
4. 実ブラウザーで５往復、同じ記録のA/D比較、通常スクロール、狭い画面、昼夜、保存復元、オフライン・PNG・BGMと既存CIを確認。
5. 独立人間２人以上の試験手順・採否材料を記録し、研究ブランチをcommit/pushしてDraft PR。既存PR変更・mainマージ・公開・販売ZIP差し替えはしない。
