# DRAWINDOW 最終理想形・公開ゲート v0.1

作成: 2026-10-18。ブランチ `feat/japanese-shiritori-v05` の現状に基づく未完了タスクの整理。**計画とテスト追加は、実機検証・ユーザーの作画確認・公開の実施を意味しない。**

## 完成形

言葉を見せない5往復の「曇りガラス越しの絵しりとり」。窓の向こうのしずくが息を吹きかけ、少し不器用に描く。プレイヤーは自分の解釈を頼りに描き返し、最後だけ10枚と9リンクを開く。

- 正解・不正解は終了まで漏らさない。しずくもプレイヤーの本当の意図は知らず、表情で正解を示さない。
- DAYは身近で軽やか、NIGHTは静かで幻想的。ルール、長さ、判定の厳しさは揃える。
- `EN/JA × DAY/NIGHT` の4通りを成立させる。日本語は意味語の表示と正規化した読み（かな）を分離する。
- DEMOは認識を模擬した体験と明示し、LIVEとスコア比較しない。画像は中立の手描き線だけ認識へ送る。
- スマホの指で気持ちよく描け、待つ・戻る・やり直すが自然にできる。共有はユーザーが選ぶ任意の操作で、無断アップロードしない。

## 現状（根拠と未検証を分ける）

main v0.4は5往復／10枚／9リンク、DAY/NIGHT、ガラス演出、64絵、キャラクター7ポーズ、DEMO、Worker、初回DAY LIVEを実装。過去の本人LIVEはAPI認識4回成功で8/9リンク。Android実機、NIGHT LIVE、初見判読性、音の主観評価、公開Worker/itch iframeは未検証。

別ブランチ `feat/japanese-shiritori-v05` は日本語UI、かな正規化、`ん`終了時の再開、Workerの日本語プロンプトを先行実装。mainには未統合。**新規日本語シナリオのテスト・実機受入をまだ完了と判定しない。**

日本語ラベル61件の先頭文字は（単純な先頭仮名で）39種類。例えば「こ」「ま」始まりが未収録。自然なLIVE認識結果の末尾文字をしずくが描けず、`uncovered_letter` で止まる可能性がある。

## P0 必ず先に解決する課題

1. **日本語LIVEの詰まり対策。** 利用頻度の高い語尾音とカタログ先頭音のギャップを集計。安全に見分けられる絵を優先して増やす。必要な音の絵がない場合は、認識結果を捏造・書き換えず、絵とスコアを保持した非比較可能な再開経路を設計する。既存の `ん` は普通のしりとり失敗として表示方法を決め、9リンクから黙って削除しない。
2. **日本語入力・得点・AI契約。** カタカナ、濁点、小文字、長音、`ん`、異表記、重複名を単体テスト。日本語の意図入力はかなの読みを正本として扱い、必要なら表示名を別に持つ。日本語でも5枚目は認識せず4回だけ。
3. **本番の情報秘匿。** DOM、aria-label、title、通信、デバッグ表示でラベル・guess・答えを結果前に出さない。DEMO／LIVEの出自を常時識別。エラー時にプレイヤーの絵が残り、無断でDEMOへ切替わらない。
4. **4組合せの受入。** EN/JA × DAY/NIGHTで各5往復、10絵、9リンク、長音処理と無回答、再挑戦、戻るを確認。日本語LIVE実画4回成功は人間が実際に描いた記録でのみ合格にする。

## P1 体験の完成

5. **昼夜の語彙。** COMMON 60% / DAY 30% / NIGHT 30% / SPECIAL 10% は「雰囲気の目標」であり、機械的比率よりも全ての必要音へのカバレッジ、判読性、反復回避を優先。まず必要音→安全度→未使用→昼夜の題材の順で選び、昼夜の難易度を変えない。
6. **しずく正式素材。** 高解像度NEUTRAL/BREATH/DRAWING/SMILEと、採用検討中のTHINKING/CURIOUS、微調整SHYを一貫した顔・髪留め・リボン・指先・アンカーへ揃える。正式採用には本人の目視承認。本人承認前は比較ページで分離。
7. **絵の判読性。** OWLを含む候補を3〜5人が初見自由回答。意図を知る制作者の評価（SAFE等）を実測正答率と言い換えない。誤解の楽しさと絵の不公平さを分離する。N/Q/X/YなどSOFTしかない組は注意。
8. **気持ちよい接触・音。** 実機A401OPで指位置一致、透明な拭き筋、保持、UNDO、端、画面回転、BGMの再生／ミュートをDAY/NIGHTで確認。Reduce Motion、画面非表示、低性能時も安全に動く。
9. **結果画面の余韻。** 10枚・9リンクを段階的に眺められる。人間が意図した言葉とAIが推測した言葉を区別し、誤認を責めない。任意の画像保存／共有を検討する場合はネタバレと権利表示に配慮し、無断アップロードしない。

## P2 公開・運用ゲート

10. **公開LIVEサーバー。** Workerの許可Origin、API秘密情報、レート制限、プロバイダー課金上限、エラー率、タイムアウト、画像非保存、ログ匿名化を確認。Cloudflare/Geminiへの本番デプロイは別の承認が必要。DEMO ZIPだけではLIVEにならない。
11. **公開パッケージ。** itch.io向けZIP、相対パス、Web Audio再生許可、360×800/720×1280、iframe、クレジット／音源・フォント・Quick Drawのライセンス、公開説明文、操作方法、スクリーンショットを確認。
12. **継続品質。** `npm test`、`npm run build`、`npm run package:itch` をPRごとにCI化。PowerShell依存の `npm run test:auth` はWindowsランナーで実施。自動テスト合格をAndroid人間試遊や本番LIVE接続と混同しない。

## 公開GO/NO-GO

- 4組合せで致命的な途中詰まりと入力不能がない。
- ゲーム内の語は最後まで隠され、4回の実認識と第5手の認識なしが確認できる。
- 最新のしずく素材・ガラス描き味・主要絵を本人が目視承認した。
- Android実機でDAY/NIGHTが遊び切れる。
- 外部参加者による読みやすさと初見の遊び方が確認できる。
- 鍵・ライセンス・バックエンド・料金・iframeを確認し、公開を明示的に承認した。

上記を満たすまでは「製品完成」「LIVE公開済み」とは呼ばない。特に現在は日本語LIVEカタログの音カバレッジがP0。
